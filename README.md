# Agente de optimización de rutas y logística de entregas

Trabajo práctico final de Desarrollo de Sistemas de IA (Grupo 3).

## Integrantes
- Matías Ezequiel Oroz
- Sara Valenzuela

## Objetivo
Construir un agente que agrupe envíos por cercanía, sugiera el orden de entrega para reducir los
kilómetros recorridos y respete las ventanas horarias. Los resultados se exponen con una API en FastAPI.

## Tecnologías
Python 3.10 o superior, Pandas, FastAPI y Uvicorn.

## Estado del proyecto
| Semana | Etapa | Estado |
|---|---|---|
| 1 | Dataset y limpieza con Pandas | En curso |
| 2 | Lógica del agente | Pendiente |
| 3 | API con FastAPI y documentación Swagger | Pendiente |

## Estructura
- `backend/`: API y lógica (`app/` con `core`, `data`, `services`, `agents`, `routers`) y datos (`data/`).
- `frontend/`: interfaz (pendiente).
- `docs/`: bitácora, diccionario de datos y decisiones.
